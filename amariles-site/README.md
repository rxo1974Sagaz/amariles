# Site da Amariles

Este repositório contém um site estático (HTML + CSS) para publicação no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub chamado `amariles` (ou outro nome de sua preferência).
2. Faça upload dos arquivos desta pasta para o repositório: `index.html`, `styles.css` e a pasta `assets/`.
3. Em *Settings* → *Pages*:
   - **Branch**: escolha `main` e o caminho `/root`.
   - Salve. O site ficará disponível em alguns instantes em `https://SEU_USUARIO.github.io/NOME_DO_REPO/`.

## Personalização
- Troque `contato@exemplo.com` e o link do LinkedIn na seção **Contato**.
- Edite os textos das seções conforme necessário.
- Para alterar a foto, substitua `assets/amariles.jpg` mantendo o mesmo nome do arquivo.

Tema visual baseado no padrão RXO (tema escuro).
