# Site da Amariles (GitHub Pages — rxo1974sagaz)

Publicação prevista em: **https://rxo1974sagaz.github.io/amariles/**

## Publicação
1. Repo `amariles` (público) no usuário **rxo1974sagaz**.
2. Suba `index.html`, `styles.css` e a pasta `assets/` na raiz da `main`.
3. **Settings → Pages**: `Branch: main` e `Folder: /(root)`.

## Personalize
- `index.html` → ajuste e-mail e LinkedIn na seção **Contato**.
- `assets/amariles.jpg` → troque a foto mantendo o nome.
- `assets/favicon.svg` → ícone do site.
